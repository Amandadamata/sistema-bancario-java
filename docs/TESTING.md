# Testing

## Running the tests

```bash
./mvnw test      # compile and run all tests
./mvnw verify    # tests plus packaging, the same command CI runs
./mvnw test -Dtest=RepositorioSqliteTest                 # one class
./mvnw test -Dtest=ContaTest#somaDeCentavosEExata        # one method
```

## Test classes

| Class | Kind | What it verifies |
|---|---|---|
| `ContaTest` | unit | Deposits, withdrawals, transfers, overdraft, exact cents, rejected amounts, statement contents |
| `ContaPoupancaTest` | unit | Yield calculation, once-per-month rule, next month, `HALF_EVEN` ties, tiny balances |
| `BancoTest` | unit | Sequential numbering, independent banks, rejected accounts not consuming numbers |
| `BancoPersistenciaTest` | unit | Saving after each operation, undoing memory when saving fails, restoring from stored data, rejecting inconsistent data, one CPF per holder |
| `CpfTest` | unit | Valid synthetic CPFs with or without punctuation; null, length, characters, repeated digits, wrong check digits; masking; messages without the number |
| `ClienteTest` | unit | Required name, CPF validation and normalization, masked `toString` |
| `MoedaTest` | unit | Parsing `100,50` / `100.50`, rejecting ambiguous input, `R$` formatting |
| `RepositorioSqliteTest` | integration | Real SQLite file: restart round trip, transfer interrupted mid-transaction, integer cents, tampered balances, constraints, schema version, unreadable files |
| `MainTest` | integration | Full menu sessions with simulated input, CPF re-entry, data surviving two program runs |

## Techniques used

- **Behavior over methods.** Failed operations always assert that state did **not** change, in
  memory and in the database.
- **Controlled failures.** `BancoPersistenciaTest` uses an in-memory repository that fails on the
  next save. `RepositorioSqliteTest` creates a database trigger that aborts in the middle of a real
  SQL transaction.
- **Restart = new objects on the same file.** A new `RepositorioSqlite` and `Banco` are created on the
  same temporary file, exactly as when the program is closed and opened again.
- **Checking that a test can fail.** The SQL transaction in `RepositorioSqlite.salvar` was removed
  temporarily; the interrupted-transfer test failed (the reload found a half-written transfer) and
  passed again after restoring it.
- **Temporary directories.** `@TempDir` gives each integration test an empty folder that JUnit
  deletes afterwards.
- **Synthetic CPFs.** Generated by the check-digit algorithm from arbitrary sequences; no real
  person's CPF is used.
- **Controlled time.** `RelogioAjustavel` only moves when the test calls `avancar(...)`.

## Coverage

Coverage is used to find untested code, not as a target. Generate a local report without changing
`pom.xml`:

```bash
./mvnw org.jacoco:jacoco-maven-plugin:0.8.13:prepare-agent test \
       org.jacoco:jacoco-maven-plugin:0.8.13:report
open target/site/jacoco/index.html
```

## Continuous integration

`.github/workflows/ci.yml` runs `./mvnw --batch-mode verify` on Java 17, 21, and 25 for every push and
pull request to `main`.
